### Learnings for future iterations:
- **Pattern**: Use useCallback to memoize functions used in useEffect dependency arrays to avoid React lint warnings
- **Pattern**: OpenAI response_format={"type": "json_object"} guarantees valid JSON without wrapper text - critical for reliable parsing
- **Pattern**: Relative date parsing with regex (`re.search(r'in\s+(\d+)\s+(day|hour|week)s?', ...)`) for natural language dates
- **Pattern**: React component structure: App (state) → TaskList (grouping) → TaskItem (individual) + TaskForm (creation)
- **Pattern**: API service layer (services/api.js) separates API logic from components - clean separation of concerns
- **Pattern**: Priority colors defined as constant object (PRIORITY_COLORS) for consistent UI styling
- **Gotcha**: React useEffect with function dependencies requires useCallback to prevent infinite loops
- **Gotcha**: npm install can take 1+ minutes - run in background with `run_in_background: true`
- **Context**: Frontend uses fetch API (no axios) for API calls - simpler, native solution
- **Context**: Agent does NOT use LangGraph in Phase 1 - direct OpenAI call is sufficient for simple extraction task
- **Context**: Agent response time was ~5 seconds due to OpenAI API latency - acceptable for Phase 1
