### Learnings for future iterations:
- **Pattern**: Using asyncio.to_thread() is critical for wrapping synchronous Databricks SQL Connector in async FastAPI routes
- **Gotcha**: Databricks SQL Warehouse can auto-stop, causing connection timeouts during initial testing
- **Context**: Health check performs `SELECT 1` query on startup to validate connection before app fully starts
- **Config**: Using signaltogrowth catalog (not default main) and todo_app schema
- **Pattern**: DatabricksClient class manages connection lifecycle with health checks
