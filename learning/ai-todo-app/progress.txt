### Learnings for future iterations:
- **Gotcha**: Databricks doesn't support DEFAULT values in column definitions - removed DEFAULT CURRENT_TIMESTAMP()
- **Gotcha**: Databricks only supports PRIMARY KEY and FOREIGN KEY constraints, not CHECK constraints - validation moved to Pydantic
- **Pattern**: Timestamps (created_at, updated_at) must be explicitly set in application code, not at DB level
- **Pattern**: Using catalog `signaltogrowth` and schema `todo_app` (not the default `main.todo_app`)
- **Pattern**: Delta Lake CDC enabled with `delta.enableChangeDataFeed` = 'true' for future Phase 3 streaming
- **Tool**: setup_database.py script automates SQL execution and verification, making schema setup repeatable

### Learnings for future iterations:
- **Pattern**: Use UUID for task_id generation - `str(uuid.uuid4())`
- **Pattern**: Timestamps handled at application layer (not DB DEFAULT) - use `datetime.utcnow().isoformat()`
- **Pattern**: Enum values accessed via `.value` when storing to DB (e.g., `task.status.value`)
- **Pattern**: Partial updates in PUT - only include provided fields in update dict
- **Pattern**: DELETE returns None for 204 No Content (FastAPI handles this)
- **Validation**: Pydantic automatically validates min_length, max_length, enum values - returns 422 on failure
- **Pattern**: All DB operations wrapped in `asyncio.to_thread()` to avoid blocking FastAPI event loop
- **Tool**: FastAPI auto-generates OpenAPI docs at /docs endpoint

- **Testing**: FastAPI TestClient provides synchronous testing without needing async fixtures

- **Pytest**: pytest.ini with pythonpath=. allows importing app module in tests

- **Pattern**: Tests verify both success cases AND error cases (422, 404)
- **Pattern**: Use fixtures for reusable test data (sample_task, test_user_id)
- **Integration**: All tests run against real Databricks (not mocked) - validates full integration
