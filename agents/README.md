# Agents

| Agent | Purpose | Tech |
|---|---|---|
| `cafe-review-intelligence` | Scrapes Google reviews for Toronto cafes, flags retention signals, analyzes them through a 5-layer behavioral framework and outputs experiments for founders | Apify, LLM, Pydantic |
| `reddit_sentiment_analyzer` | Finds Reddit posts and comments about a brand and analyzes sentiment and trends | Reddit scraping, Supabase |
| `research_agent` | Turns a raw observation into 10-15 evidence-informed research angles, run via `/research-angles` in Claude Code | Claude Code subagents |

Each agent has its own README with setup and run instructions.
